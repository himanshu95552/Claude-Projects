# A/B test variants

Run one test at a time. Change only the variable in each test, keep image, audience and budget identical across variants, and let each variant collect enough impressions before judging (LinkedIn suggests at least a few hundred clicks per variant).

Job-title test (T3): run as one campaign per audience with the matching job-title targeting, or one campaign with all titles to see which message each title responds to.
